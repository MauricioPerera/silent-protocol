# src/render

## Overview

Zero-asset procedural WebGL2 rendering subsystem for **SILENT PROTOCOL** (`Three.js r160`). This directory encapsulates deterministic PBR material libraries (`Albedo`, `ORM`, `Normal` synthesized via TypedArray node operators adapted from `storytold/materialcraft` `MIT` with instant `256x256` boot and non-blocking `1024x1024` / `512x512` Web Worker upgrade) + `PMREM` reflections, articulated Forward Kinematics (`FK`) humanoid rigs and analytical 2-bone Inverse Kinematics (`IK`) robotic rigs, procedural beveled/lathed Mansion Aurora furniture and static geometry batching, and linear `HalfFloatType` MSAA `4x` HDR Bloom + `AgXToneMapping` post-processing.

Modules in `src/render/` depend only on `../../vendor/three.module.js`, pure configuration/math exports (`../config.js`, `../mathx.js`), and internal helpers `mats.js` / `mats_worker.js -> ./mats_ops.js` and `rigs.js -> ./props.js` (`mergeBufferGeometries`), and are consumed by `../render.js` and `../diag.js`.

## Interface

- **Procedural PBR Material Library (`./mats_ops.js`, `./mats_worker.js`, `./mats.js`)**:
  - `[src/render/mats_ops.js:ARCHETYPES]`, `[src/render/mats_ops.js:mcLevels]`, `[src/render/mats_ops.js:createBakeScratch]`, `[src/render/mats_ops.js:bakeArchetypeBuffers]` — Pure zero-Three.js TypedArray node-graph engine (`Levels`, `Directional Warp`, `Slope Warp`, integer-lattice `Directional Blur`, Voronoi `F1`/`F2-F1`, `size / 256` `Sobel Normal`, 8-direction `HBAO`, and `Curvature` edge-wear/cavity-grime) shared across the main thread, `./mats_worker.js` (`Transferable` `ArrayBuffer` worker), and Node.js tests.
  - `[src/render/mats.js:createMaterialLibrary]` — `createMaterialLibrary(renderer, quality = 'high')`: synchronously boots `256x256` `DataTexture` triplets (`map` in `SRGBColorSpace`, `ormMap` with `R=HBAO, G=Roughness, B=Metalness` in `NoColorSpace`, and tangent-space `normalMap` in `NoColorSpace` with hardware `anisotropy <= 8`), progressively upgrades in place via `./mats_worker.js` to `1024x1024` (`high`) or `512x512` (`medium`), generates an indoor/night `PMREMGenerator` environment cubemap (`envMap`), and returns `{ quality, size, targetSize, archetypes, sets, envMap, sharedSet, wallOpaque, wallXray, trimOpaque, trimXray, brushedSteel, paintedMetal, darkMetal, gold, wood, warmWood, ceramic, white, concrete, leather, darkLeather, fabric, green, glass, water, glowCyan, glowAmber, glowRed, glowGold, glowGreen, glowWarm, makeZoneFloorMaterial, makeCharacterMaterials, setQuality, dispose }` (also re-exporting `ARCHETYPES`, `mcLevels`, `createBakeScratch`, `bakeArchetypeBuffers`).
- **Articulated FK & IK Rigs (`./rigs.js`)**:
  - `[src/render/rigs.js:solveTwoBoneIK]` — `solveTwoBoneIK(l1, l2, targetZ, targetYDown) => { hipRotX, kneeRotX }`: analytical law-of-cosines 2-bone IK solver clamping target reach to `[|l1 - l2| + 1e-4, l1 + l2 - 1e-4]`.
  - `[src/render/rigs.js:createHumanoidRig]` — `createHumanoidRig(outfitId, isPlayer, matLib, profile = {}) => { group, parts, accessories, held, profile, outfitId, _stripped, applyOutfit, resetPose, setHeld, setVisorColor, setInstinctHighlight, setStripped, pose, dispose }`: builds sculpted human/S-7 hierarchies (`hips -> torso` with merged `chest`, `head -> skull` with merged `hair` on hatless NPCs, `shoulderL/R -> elbowL/R, thighL/R -> kneeL/R`) using per-character material instances (`cloth` with `vertexColors: true` aliased as `accent`, `skin` with `vertexColors: !isAndroid` aliased as `hairMat`, `vestMat`, `visor`) backed by shared `DataTexture` maps. Pre-merges internal rigid sub-parts per material/vertex-color slice, differentiates VIP targets (`vandermeer` ceremonial tailcoat/regalia + executive hair/goatee, `kessler` cyan AR holo-visor + neural collar + chignon), enforcers (`chief` beret/radio, `chef` grand toque/neckerchief, `sci_senior` glasses/stole), and gala guests, and drives multi-harmonic locomotion plus contextual poses/props (`speech`, `work` datapad, `drink:*` goblet/mug, `look`, `suspicious`, `investigate`, `shock`, `panic`, `flee`, `sick`, `combat` sidearm, `crouch`, `jackedIn`, `dragging`, `aiming`, `channel`, `dead`, `sleep`).
  - `[src/render/rigs.js:createBotRig]` — `createBotRig(kind, matLib) => { group, chassis, gimbal, pose, dispose }`: builds armored quadruped maintenance (`maint`) and security (`sec`) robotic units driven by `solveTwoBoneIK` across 4 articulated legs (`femur -> tibia`), reflecting `hijacked` and `disabled` states on the chassis LEDs and multi-optic sensor gimbal.
- **Procedural Props, Vents & Static Batching (`./props.js`)**:
  - `[src/render/props.js:scaleGeometryUVs]` & `[src/render/props.js:scaleBoxUVs]` — World-space UV scaling helpers preventing texture stretching across variable-sized floors, walls, and furniture boxes.
  - `[src/render/props.js:mergeBufferGeometries]` — `mergeBufferGeometries(geos) => THREE.BufferGeometry | null`: normalizes indexed/non-indexed geometries to `{ position, normal, uv }` attributes (preserving optional 3-component `color` attributes when present) and concatenates them into a single `BufferGeometry`.
  - `[src/render/props.js:mergeStaticMeshes]` — `mergeStaticMeshes(roots) => { meshes, dispose }`: traverses static scene roots, skips `userData.dynamic` hierarchies and `material.transparent === true` meshes, transforms static geometries into world space, merges them by `(material, castShadow, receiveShadow)`, removes/disposes source meshes, and returns batched meshes.
  - `[src/render/props.js:buildLightCone]` — `buildLightCone(light, matLib) => { group, cone, setFactor, dispose }`: builds static ceiling `housing` (candidate for `mergeStaticMeshes`) plus dynamic `bulb` and soft additive volumetric light `cone` (`userData.dynamic = true`, `depthWrite: false`, `toneMapped: false`) with custom Fresnel edge fade.
  - `[src/render/props.js:buildPropMesh]` — `buildPropMesh(prop, matLib, refs) => THREE.Group`: constructs Mansion Aurora furniture, lab equipment, pre-merged 3-mesh `chandelier` (`userData.dynamic = true`), and double-sided low `'vent'` grilles, populating dynamic handles on `refs` (`puddleLab`, `terminalScreen`, `poolWater`, `chandelier`, `boatLight`, `ownedMaterials`).
- **HDR MSAA + Bloom + AgX Post-Processing (`./postfx.js`)**:
  - `[src/render/postfx.js:supportsHdrPostFX]` — `supportsHdrPostFX(renderer) => boolean`: verifies `EXT_color_buffer_float` or `EXT_color_buffer_half_float` on WebGL2 (or `EXT_color_buffer_half_float` on WebGL1).
  - `[src/render/postfx.js:createPostFX]` — `createPostFX(renderer, width, height, quality) => { enabled, resize, setQuality, compile, render, dispose }`: renders the linear scene into a `HalfFloatType` `WebGLRenderTarget` (`samples: 4` in `high`, `2` in `medium`), precompiles shaders against `sceneRT` via `compile(scene, camera)`, runs a soft-threshold prefilter + mipmap downsample/tent-upsample Bloom pyramid (`toneMapped: false`), and composites to screen using Three.js native `#include <tonemapping_fragment>` (`AgXToneMapping`) and `#include <colorspace_fragment>`. Falls back cleanly to direct `<canvas>` rendering in `low` quality or when float FBO extensions are absent.

## Invariants

- **Shared Textures, Isolated Mutable Materials**: Shared `DataTexture` maps in `matLib.sets` are never mutated by external scene consumers (only `matLib.setQuality(nextQuality)` hot-swaps their underlying `THREE.Source` buffers in-place across `1024/512/256` presets); `createHumanoidRig` and `createBotRig` allocate per-entity material instances (`makeCharacterMaterials`, `eyeMat`) so outfit swaps (`applyOutfit`, `setStripped`, `setInstinctHighlight`, `setVisorColor`) and state tints never mutate materials shared across other NPCs or props (`matLib.sharedSet`).
- **Shadow Caster Discipline**: On humanoid rigs, `castShadow = true` is restricted to `torso` and `thighL`/`thighR` on S-7 (`3` meshes) and `torso` on NPCs (`1` mesh); on quadruped robotic rigs (`createBotRig`), `castShadow = true` is restricted to `hull` (`1` mesh); `buildLightCone` and `'vent'` slats never cast shadows.
- **Single Tone-Mapping & Color-Space Conversion**: Intermediate Bloom shaders set `toneMapped: false`, while `renderer.toneMapping` stays `THREE.AgXToneMapping`; Three.js `r160` automatically suppresses tone-mapping when rendering to offscreen `WebGLRenderTarget`s and applies `AgXToneMapping` + `SRGBColorSpace` encoding exactly once on the final screen pass (`setRenderTarget(null)`).
- **Zero-Leak Lifecycle**: `mergeStaticMeshes`, `mergeBufferGeometries` callers, `rig.dispose()`, `postfx.dispose()`, and `matLib.dispose()` release owned `BufferGeometry`, `Material`, `DataTexture`, and `WebGLRenderTarget` allocations.
